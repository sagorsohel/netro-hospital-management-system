# Netro Hospital Management System

A Hospital Management Dashboard built with **React**, **Vite**, **Tailwind CSS**, **Shadcn UI**, and **Redux Toolkit**.

## Features
- **Redux Toolkit State Architecture**: Centralized store managing live stats, doctors roster, appointments, and status transitions.
- **Shadcn UI Components**: Clean Button, Card, Badge, Input, and Table components styled with Tailwind CSS.
- **Appointment Operations**: Real-time filtering, status confirmation, completion, cancellation, and new booking modal.
- **Specialist Management**: Doctor directory with ratings, active status badges, and department tags.
- **Modern Responsive Medical Dashboard**: Tailored medical palette and responsive sidebar layout.

## Tech Stack
- **React 19**
- **Vite 6**
- **TypeScript**
- **Tailwind CSS v4**
- **Shadcn UI styled components**
- **Redux Toolkit & React-Redux**
- **Lucide React Icons**

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build production bundle:
   ```bash
   npm run build
   ```
